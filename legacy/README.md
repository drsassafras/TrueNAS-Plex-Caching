# Legacy scripts

These are the original bash scripts, kept for reference. They are replaced by the Plex Cache app in the repository root, which does the same jobs with a web UI and without Tautulli.

| Script | Replaced by |
|---|---|
| `plex_preload_l2arc2.sh` (and the older `plex_preload_l2arc.sh`) | Library warm-up |
| `preload_current_media.sh` | Now-playing preload |
| `plex_prefetch_next.sh` | Next-episode prefetch |

Your `plex-l2arc.conf` can be imported from the app's Settings page.
